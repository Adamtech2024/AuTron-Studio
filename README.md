## 🏗️ THE "MAKE" PHILOSOPHY
In AuTron, everything is a simple instruction. You can use the word `make` at the start of every line to keep your thoughts organized.

### 1. TALKING TO THE COMPUTER
```autron
make say "Hello World"
make say "Welcome back!"
```

### 2. SAVING INFORMATION
No complex types or brackets. Just tell AuTron to save it.
```autron
make set score to 100
make let name be "Adam"
```

### 3. HUMAN MATH
Forget the plus and minus signs if you want. Use real words.
```autron
make add 10 to score
make take 5 from enemy_hp
make multiply damage by 2
```

### 4. REPEATING ACTIONS
```autron
make loop 10
    make say "This is easy!"
end
```

### 5. CHECKING THINGS
```autron
make if score is 100
    make say "You Win!"
end
```

### 6. WAITING
```autron
make wait 3 seconds
```

## 🎨 WEB DEVELOPMENT (AWL)
The UI engine also uses the same `make` style:
- `make web hero`: A big header.
- `make web button "Click Me"`: A button.
- `make web box`: A container.
